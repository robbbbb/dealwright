Design notes — what's locked in this mockup

  • Session = facts only. No prices, no ROI, no voice, no VA picks. Test for any field: which engine reads this?
  • Chip semantics hold: red = missing/gap (follow-ups, blocked rows), amber = estimate labels everywhere numbers are shown, teal = neutral info (provenance, mode explanations), green = confirmed.
  • Provenance is visible: ruleset version, model, run cost, confirmed/missing counts — the audit trail is a first-class UI element, not a log file.
  • Nothing invented: missing hours → the row goes qualitative with a visible reason; "nobody today" → qualitative, no fake baseline; revenue inputs stay disabled until the workflow actually runs.
  • Estimate freezes math: band values + version snapshot on compute; scenario toggle re-renders stored rows; proposal generation consumes the snapshot.
