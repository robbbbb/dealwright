Usage principles

A quiet, disciplined system makes the premium cues feel intentional.

01

Give it room

Keep the lockup away from card edges, headlines, and dense interface controls.

02

Use gold sparingly

Reserve gold for the mark and premium moments; green remains the primary action color.

03

Protect contrast

Use the dark wordmark on white or canvas and the light wordmark on deep green only.

The design system

This page is the canonical entry point. Tokens, components, and every screen live one click away.

A

Full tokens & components

docs/mockups/theme.html — every CSS variable, button, chip, form, and type style with usage rules. Build UI from these tokens verbatim; never invent colors.

B

All screens

docs/mockups/index.html — gallery of every mocked screen (landing, dashboard, auth, proposals), tagged by audience.

C

Chip semantics = product rules

Green is verified/accepted. Amber is always "estimate". Gold is premium only. Red is gaps/errors. Teal is neutral info. Never violate these mappings in any UI.

Production note: the DW monogram and wordmark are live system-font text (weight 300, wide tracking). Rendering is consistent across the app's supported stacks; outline the glyphs to paths only when exporting self-contained print/PDF masters.
